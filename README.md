This is the repository from the paper "Nonlinear Feature Selection for Multi-target Regression Problems". The paper URL: [https://arxiv.org/pdf/1903.07045.pdf](https://link.springer.com/article/10.1007/s42979-025-03880-y)


The code of the variant using numerical approximation entitled "Neural Network-Based Approach for Supervised Nonlinear Feature Selection" is also given.
